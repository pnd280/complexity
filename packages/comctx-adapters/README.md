# Comctx Adapters

A collection of pre-built adapters for [Comctx](https://github.com/molvqingtai/comctx) that simplify cross-context communication in browser extensions. These adapters implement Comctx's `Adapter` interface and use [WebExt Bridge](https://github.com/antfu/webext-bridge) as the underlying communication layer, making it easy to leverage Comctx's powerful RPC capabilities in browser extensions without writing custom communication code.
